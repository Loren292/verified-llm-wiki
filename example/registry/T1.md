# T1 · Does `amount` include shipping?

**Asked to:** the store owner.

**Why it isn't in the data:** the export has a single `amount` per order and no shipping column.

**What's at stake:** if it includes shipping, every AOV figure includes the shipping fee of every
order. The decision on how to report AOV (P1) waits for this answer.

**Plan B meanwhile:** AOV is reported as is, with the limit stated next to it in
[[metrics#Limits]].
